# BT4 Sparking Controls — 0.6 Test

Ekstrak ZIP Windows dan jalankan BT4-SparkingControls.exe. Pilih BT4decomp.exe atau berkas .cmd dalam folder yang sama, lalu simpan dan mulai. Versi 0.6 Test mencakup perbaikan font, peluncuran CMD, benturan energi, dan potret. Pengaturan tetap tersimpan. Khusus Windows.

[Windows ZIP](https://github.com/vini2227/BT4-SparkingControls/releases/download/v0.6-test/BT4-SparkingControls-0.6-Test-Windows.zip) · [0.6 Changes / English](../../CHANGELOG.md) · [Full English guide](../../README.md)

## Kontrol

□ = Kotak; △ = Segitiga; ○ = Lingkaran; LS = stik kiri. Panah LS berarti stik, bukan D-pad. Navigasi menu biasa tetap memakai kontrol asli.

| Tombol / kombinasi | Aksi |
| --- | --- |
| `□` | Serangan Rush |
| `△` | Tembakan Ki |
| `X` | Gerakan dan dash native |
| `R2` | Mengisi Ki |
| `L1` | Naik |
| `L2` | Turun |
| `R2 + L1` | Z Dash vertikal ke atas |
| `R2 + L2` | Z Dash vertikal ke bawah |
| `R1` | Bertahan di luar kombo sendiri yang didukung |
| `R2 + □` | Serangan super 1 |
| `R2 + △` | Serangan super 2 |
| `R2 + ○` | Serangan ultimate sesuai persyaratan native |
| `R2 + D-pad ↑ / ↓` | Kemampuan 1 |
| `R2 + D-pad ← / →` | Kemampuan 2 |
| `○` | Sikap serangan balik native |
| `R1 (combo)` | Teleport maju native dalam kombo yang didukung |
| `R1 + LS (combo)` | Teleport berarah native dalam kombo tersebut |
| `R1 + □` | Cengkeraman biasa |
| `R1 + LS↓ + □` | Cengkeraman tanah alternatif, hanya stik |
| `LS↑ + △` | Cengkeraman tanah dengan input asli |
| `R3` | Emergency Blaster Wave jika syarat native terpenuhi |
| `L3` | Mencari / mengunci sasaran |
| `Select / View` | Mengganti kamera |
| `D-pad ↑` | Tahan: transformasi/fusi |
| `D-pad ←` | Tahan: mengganti anggota tim |
| `D-pad ↓ / → (no R2)` | Diblokir dalam pertarungan untuk mencegah input tak sengaja |

Serangan spesial bisa dipilih saat R2 sudah ditahan. Untuk terus mengisi serangan, tahan tombol serangan yang ditetapkan; melepas R2 saja tidak melepaskannya. Saat diminta, gunakan □ + arah yang ditunjukkan untuk boost asli. Overlay hanya menutupi Segitiga dan membiarkan gambar tangan terlihat. Pintasan kemampuan bukan salinan persis kontrol ZERO.

○ meminta sikap serangan balik BT4 dengan prioritas di atas serangan yang ditahan saat kombo didukung; bukan seluruh sistem Perception/Super Perception ZERO. Teleport R1 mengikuti biaya Ki/jendela native, tanpa jaminan muncul di belakang musuh atau tetap diam. R1 + □ diprioritaskan dan menghasilkan X–lepas–X, tergantung jangkauan dan jendela aksi. Ketuk ganda X asli tetap ada. Cengkeraman tanah tidak menerima D-pad ↓; LS↑ + ○ tidak memicunya. R3 memakai biaya kesehatan dan syarat BT4, bukan Revenge Counter berbasis Skill Count ZERO. Pintasan fisik R3 transformasi/fusi asli dikonsumsi; kartu menghasilkan input yang diperlukan.

## Transformasi, fusi dan pergantian

Tahan D-pad ↑ lalu tekan □/△/X/○ sesuai kartu; lepas ↑ untuk menutup. L1/R1 berganti antara bentuk dan fusi hanya bila keduanya tersedia. Kategori kosong dilewati; karakter dengan fusi saja langsung membuka fusi. Tahan D-pad ← untuk mengganti anggota tim. Syarat pasangan, bentuk, pengukur, cooldown dan keadaan pertarungan BT4 tetap berlaku. Posisi kartu konsisten, slot kosong dan bilah kesehatan cadangan. Daring, panel lokal ada di kiri bahkan sebagai Pemain 2, tanpa mengubah sisi logis input.


## HUD / F6 · F7 · F8

F6: attack panel · F7: outer frame · F8: panel placement. Configure shortcuts and shortcut lock in the launcher. Settings: `%LOCALAPPDATA%\BT4-SparkingControls`.
