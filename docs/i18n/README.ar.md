## التحكم

□ = مربع؛ △ = مثلث؛ ○ = دائرة؛ LS = العصا اليسرى. أسهم LS تعني العصا لا أزرار الاتجاهات D-pad. تحتفظ القوائم العادية بتحكم اللعبة الأصلي.

| الزر / المجموعة | الإجراء |
| --- | --- |
| `□` | هجمات Rush |
| `△` | طلقات Ki |
| `X` | الحركة والاندفاع الأصليان |
| `R2` | شحن Ki |
| `L1` | الصعود |
| `L2` | الهبوط |
| `R2 + L1` | اندفاع Z عمودي إلى الأعلى |
| `R2 + L2` | اندفاع Z عمودي إلى الأسفل |
| `R1` | الدفاع خارج مجموعات هجماتك المدعومة |
| `R2 + □` | الهجوم الخارق 1 |
| `R2 + △` | الهجوم الخارق 2 |
| `R2 + ○` | الهجوم النهائي وفق شروط اللعبة |
| `R2 + D-pad ↑ / ↓` | المهارة 1 |
| `R2 + D-pad ← / →` | المهارة 2 |
| `○` | وضعية الهجوم المضاد الأصلية |
| `R1 (combo)` | انتقال أمامي أصلي أثناء مجموعات الهجمات المدعومة |
| `R1 + LS (combo)` | انتقال باتجاه محدد أثناء تلك المجموعات |
| `R1 + □` | إمساك عادي |
| `R1 + LS↓ + □` | إمساك أرضي بديل باستخدام العصا فقط |
| `LS↑ + △` | إمساك أرضي بالأمر الأصلي |
| `R3` | Emergency Blaster Wave عند استيفاء شروط اللعبة |
| `L3` | البحث / تثبيت الهدف |
| `Select / View` | تغيير الكاميرا |
| `D-pad ↑` | استمرار الضغط: التحولات/الاندماجات |
| `D-pad ←` | استمرار الضغط: تبديل عضو الفريق |
| `D-pad ↓ / → (no R2)` | محظورة أثناء القتال لمنع الأوامر غير المقصودة |

يمكن اختيار الهجمات الخاصة مع استمرار الضغط على R2. لمواصلة شحن هجمة، استمر في ضغط زر الهجوم المخصص؛ تحرير R2 وحده لا يحرر ذلك الزر. عند ظهور طلب التعزيز، استخدم □ مع الاتجاه المطلوب لإرسال أمر boost الأصلي. يغطي الرمز المثلث فقط ويترك رسم اليد ظاهراً. اختصارات المهارات ليست نسخة مطابقة لتحكم ZERO.

يطلب ○ وضعية BT4 المضادة، بأولوية على أزرار الهجوم المضغوطة خلال المجموعات المدعومة، ولا يضيف نظام Perception/Super Perception الكامل من ZERO. تحتفظ انتقالات R1 بتكلفة Ki ونوافذ الإلغاء الأصلية ولا تضمن الظهور خلف العدو أو البقاء في المكان. يأخذ R1 + □ الأولوية ويولد X ثم تحريره ثم X، مع بقاء قيود المدى والتوقيت. يبقى ضغط X مرتين الأصلي متاحاً. الإمساك الأرضي لا يقبل D-pad ↓، ولا ينفذه LS↑ + ○. يستخدم R3 تكلفة الصحة وشروط BT4 لا Revenge Counter المعتمد على Skill Count في ZERO. تُستهلك اختصارات R3 المادية الأصلية للتحول/الاندماج، وتولّد البطاقات الأوامر المطلوبة داخلياً.

## التحول والاندماج وتبديل الفريق

اضغط مطولاً D-pad ↑ واختر □/△/X/○ حسب البطاقة؛ حرّر ↑ للإغلاق. يتنقل L1/R1 بين التحول والاندماج فقط إذا توفرت الفئتان. تُتجاوز الفئات الفارغة، وتفتح الشخصيات التي تملك اندماجاً فقط تلك الفئة مباشرة. اضغط مطولاً D-pad ← لتبديل زميل. تظل شروط الشريك والشكل والمقاييس والتبريد وحالة القتال في BT4 مطلوبة. مواقع البطاقات موحدة مع خانات فارغة وأشرطة صحة الاحتياط. عبر الإنترنت تظهر اللوحات المحلية يساراً حتى للاعب 2 دون تغيير الجانب المنطقي للمدخلات.


## HUD / F6 · F7 · F8

F6: attack panel · F7: outer frame · F8: panel placement. Configure shortcuts and shortcut lock in the launcher. Settings: `%LOCALAPPDATA%\BT4-SparkingControls`.
