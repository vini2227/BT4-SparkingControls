## Управление

□ = Квадрат; △ = Треугольник; ○ = Круг; LS = левый стик. Стрелки LS означают стик, не крестовину. Обычные меню сохраняют исходное управление.

| Кнопка / сочетание | Действие |
| --- | --- |
| `□` | Атаки Rush |
| `△` | Выстрелы Ki |
| `X` | Обычное движение и рывки BT4 |
| `R2` | Зарядка Ki |
| `L1` | Подняться |
| `L2` | Опуститься |
| `R2 + L1` | Вертикальный Z Dash вверх |
| `R2 + L2` | Вертикальный Z Dash вниз |
| `R1` | Защита вне своих поддерживаемых комбо |
| `R2 + □` | Суператака 1 |
| `R2 + △` | Суператака 2 |
| `R2 + ○` | Ультимативная атака по условиям BT4 |
| `R2 + D-pad ↑ / ↓` | Способность 1 |
| `R2 + D-pad ← / →` | Способность 2 |
| `○` | Родная стойка контратаки BT4 |
| `R1 (combo)` | Телепорт вперёд в поддерживаемом комбо |
| `R1 + LS (combo)` | Телепорт по направлению в таком комбо |
| `R1 + □` | Обычный захват |
| `R1 + LS↓ + □` | Альтернативный захват на земле, только стик |
| `LS↑ + △` | Захват на земле исходной командой |
| `R3` | Emergency Blaster Wave при выполнении условий игры |
| `L3` | Поиск / захват цели |
| `Select / View` | Смена камеры |
| `D-pad ↑` | Удерживать: превращения/слияния |
| `D-pad ←` | Удерживать: смена бойца |
| `D-pad ↓ / → (no R2)` | Заблокированы в бою против случайных команд |

Спецприёмы можно выбирать при уже удерживаемом R2. Для продолжения зарядки удерживайте назначенную кнопку атаки: отпускание только R2 не отпускает её. При запросе усиления используйте □ + указанное направление. Накладка заменяет лишь Треугольник, оставляя руку видимой. Сочетания способностей не являются точной копией ZERO.

○ вызывает стойку BT4 с приоритетом над удерживаемыми атаками в поддерживаемых комбо, а не полную механику Perception/Super Perception из ZERO. Телепорты R1 сохраняют родные требования Ki и окна действий; позиция позади врага или неподвижность не гарантируются. R1 + □ имеет приоритет и создаёт X–отпускание–X, с ограничениями дальности и окна. Оригинальный двойной X сохранён. Захват на земле не использует крестовину ↓; LS↑ + ○ его не вызывает. R3 использует здоровье и условия BT4, не очки способностей Revenge Counter из ZERO. Физические исходные команды превращения/слияния R3 перехватываются; карты создают нужные нажатия.

## Превращения, слияние и смена бойца

Удерживайте крестовину ↑ и нажмите □/△/X/○ с карты; отпустите ↑ для закрытия. L1/R1 переключают превращения/слияния только при наличии обеих категорий. Пустые пропускаются; если есть лишь слияние, открывается оно. Удерживайте крестовину ← для смены бойца. Партнёр, форма, шкалы, откаты и состояние боя должны соответствовать BT4. Единые позиции карт, пустые ячейки и здоровье резерва. Онлайн локальные панели слева даже для Игрока 2, без изменения логической стороны ввода.


## HUD / F6 · F7 · F8

F6: attack panel · F7: outer frame · F8: panel placement. Configure shortcuts and shortcut lock in the launcher. Settings: `%LOCALAPPDATA%\BT4-SparkingControls`.
