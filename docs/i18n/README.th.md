## การควบคุม

□ = สี่เหลี่ยม, △ = สามเหลี่ยม, ○ = วงกลม, LS = อนาล็อกซ้าย ลูกศร LS หมายถึงอนาล็อก ไม่ใช่ D-pad เมนูปกติยังใช้การควบคุมเดิม

| ปุ่ม / ชุดคำสั่ง | การทำงาน |
| --- | --- |
| `□` | โจมตี Rush |
| `△` | ยิง Ki |
| `X` | เคลื่อนที่และพุ่งแบบเดิม |
| `R2` | ชาร์จ Ki |
| `L1` | ลอยขึ้น |
| `L2` | ลอยลง |
| `R2 + L1` | Z Dash แนวตั้งขึ้น |
| `R2 + L2` | Z Dash แนวตั้งลง |
| `R1` | ป้องกันนอกคอมโบของตนที่รองรับ |
| `R2 + □` | ท่าพิเศษ 1 |
| `R2 + △` | ท่าพิเศษ 2 |
| `R2 + ○` | ท่าไม้ตายตามเงื่อนไขเดิม |
| `R2 + D-pad ↑ / ↓` | สกิล 1 |
| `R2 + D-pad ← / →` | สกิล 2 |
| `○` | ท่าตั้งรับสวนกลับเดิม |
| `R1 (combo)` | วาร์ปไปด้านหน้าในคอมโบที่รองรับ |
| `R1 + LS (combo)` | วาร์ปตามทิศทางในคอมโบดังกล่าว |
| `R1 + □` | จับตามปกติ |
| `R1 + LS↓ + □` | จับศัตรูล้มแบบทางเลือก ใช้อนาล็อกเท่านั้น |
| `LS↑ + △` | จับศัตรูล้มด้วยคำสั่งเดิม |
| `R3` | Emergency Blaster Wave เมื่อผ่านเงื่อนไขเดิม |
| `L3` | ค้นหา / ล็อกเป้าหมาย |
| `Select / View` | เปลี่ยนกล้อง |
| `D-pad ↑` | กดค้าง: แปลงร่าง/ฟิวชัน |
| `D-pad ←` | กดค้าง: สลับสมาชิกทีม |
| `D-pad ↓ / → (no R2)` | ถูกบล็อกระหว่างต่อสู้เพื่อกันกดพลาด |

เลือกท่าพิเศษได้ขณะกด R2 ค้างอยู่ หากต้องการชาร์จต่อให้ค้างปุ่มโจมตีที่กำหนด การปล่อยเฉพาะ R2 จะไม่ปล่อยปุ่มโจมตี เมื่อมีคำแนะนำ boost ให้ใช้ □ + ทิศทางที่ระบุ ภาพซ้อนทับจะแทนเฉพาะสามเหลี่ยมและไม่บังรูปมือ คีย์ลัดสกิลเป็นรูปแบบของโปรแกรมนี้ ไม่ใช่การจำลอง ZERO ทุกปุ่ม

○ เรียกท่าสวนกลับเดิมของ BT4 โดยมีลำดับก่อนปุ่มโจมตีที่กดค้างในคอมโบที่รองรับ ไม่ใช่ระบบ Perception/Super Perception ทั้งหมดของ ZERO วาร์ป R1 ยังต้องมี Ki และจังหวะยกเลิกตามเกมเดิม ไม่รับประกันว่าจะอยู่หลังศัตรูหรืออยู่กับที่ R1 + □ มีลำดับก่อนและส่ง X–ปล่อย–X แต่ยังต้องอยู่ในระยะและจังหวะที่ถูกต้อง ยังคงการกด X สองครั้งเดิมไว้ การจับศัตรูล้มไม่ใช้ D-pad ↓ และ LS↑ + ○ จะไม่เรียกท่านี้ R3 ใช้พลังชีวิตและเงื่อนไขของ BT4 ไม่ใช่ Revenge Counter ที่ใช้ Skill Count ของ ZERO คำสั่งแปลงร่าง/ฟิวชัน R3 เดิมจะถูกดักไว้ และการ์ดสร้างคำสั่งที่ต้องใช้ภายใน

## แปลงร่าง ฟิวชัน และสลับตัว

กด D-pad ↑ ค้างแล้วเลือก □/△/X/○ ตามการ์ด ปล่อย ↑ เพื่อปิด L1/R1 สลับหมวดได้เมื่อมีทั้งแปลงร่างและฟิวชัน ข้ามหมวดว่างและเปิดฟิวชันทันทีถ้ามีเพียงอย่างเดียว กด D-pad ← ค้างเพื่อสลับทีม ยังต้องผ่านเงื่อนไขคู่ร่วมร่าง รูปแบบ เกจ คูลดาวน์ และสถานะการต่อสู้ของ BT4 ทั้งสามเมนูใช้ตำแหน่งการ์ดคงที่ แสดงช่องว่างและแถบชีวิตตัวสำรอง ออนไลน์จะแสดงแผงของผู้เล่นในเครื่องทางซ้ายแม้เป็นผู้เล่น 2 โดยไม่เปลี่ยนฝั่งอินพุตจริง

F6: attack panel · F7: outer frame · F8: panel placement. Configure shortcuts and shortcut lock in the launcher. Settings: `%LOCALAPPDATA%\BT4-SparkingControls`.
