# BT4 Sparking Controls — 0.6 Test

Extrayez le ZIP Windows et lancez BT4-SparkingControls.exe. Sélectionnez BT4decomp.exe ou un fichier .cmd placé dans le même dossier, puis enregistrez et démarrez. La version 0.6 Test inclut les corrections des polices, du lancement CMD, des duels et des portraits. Les réglages sont conservés. Windows uniquement.

[Windows ZIP](https://github.com/vini2227/BT4-SparkingControls/releases/download/v0.6-test/BT4-SparkingControls-0.6-Test-Windows.zip) · [0.6 Changes / English](../../CHANGELOG.md) · [Full English guide](../../README.md)

## Commandes

□ = Carré ; △ = Triangle ; ○ = Rond ; LS = stick gauche. LS et les flèches désignent le stick, pas la croix directionnelle. La navigation des menus ordinaires reste celle du jeu.

| Touche / combinaison | Action |
| --- | --- |
| `□` | Attaques Rush |
| `△` | Tirs de Ki |
| `X` | Déplacements et dash natifs |
| `R2` | Charger le Ki |
| `L1` | Monter |
| `L2` | Descendre |
| `R2 + L1` | Z Dash vertical vers le haut |
| `R2 + L2` | Z Dash vertical vers le bas |
| `R1` | Garde hors de vos combos compatibles |
| `R2 + □` | Super attaque 1 |
| `R2 + △` | Super attaque 2 |
| `R2 + ○` | Attaque ultime, selon les conditions natives |
| `R2 + D-pad ↑ / ↓` | Compétence 1 |
| `R2 + D-pad ← / →` | Compétence 2 |
| `○` | Posture de contre native |
| `R1 (combo)` | Téléportation avant native pendant les combos compatibles |
| `R1 + LS (combo)` | Téléportation directionnelle native pendant ces combos |
| `R1 + □` | Projection normale |
| `R1 + LS↓ + □` | Projection au sol alternative, stick uniquement |
| `LS↑ + △` | Projection au sol avec la commande originale |
| `R3` | Emergency Blaster Wave, selon les conditions natives |
| `L3` | Rechercher / verrouiller la cible |
| `Select / View` | Changer de caméra |
| `D-pad ↑` | Maintenir : transformations/fusions |
| `D-pad ←` | Maintenir : changement de coéquipier |
| `D-pad ↓ / → (no R2)` | Bloqués en combat pour éviter les commandes accidentelles |

Les attaques peuvent être choisies lorsque R2 est déjà maintenu. Pour charger une attaque spéciale, continuez à maintenir sa touche d’attaque ; relâcher R2 seul ne la relâche pas. Lors d’une demande de boost, □ + direction indiquée transmet la commande d’origine. Le symbole remplace seulement le Triangle et laisse la main visible. Les raccourcis de compétences ne prétendent pas reproduire exactement ceux de ZERO.

○ demande le contre de BT4, prioritaire sur les attaques maintenues pendant les combos compatibles ; ce n’est pas le système complet Perception/Super Perception de ZERO. Les téléportations de R1 gardent leurs coûts et fenêtres natifs, sans garantir une arrivée derrière l’adversaire ou une position immobile. R1 + □ est prioritaire et produit X–relâchement–X, soumis à la portée et aux fenêtres du jeu. Le double X original reste disponible. La projection au sol n’utilise pas la croix ↓ ; LS↑ + ○ ne la déclenche pas. R3 utilise les conditions et le coût en vie de BT4, pas le Revenge Counter de ZERO basé sur les points de compétence. Les anciennes commandes physiques R3 de transformation/fusion sont consommées ; les cartes génèrent les entrées requises.

## Transformations, fusion et changement

Maintenez la croix ↑ puis appuyez sur □/△/X/○ indiqué sur la carte ; relâchez ↑ pour fermer. L1/R1 alternent entre transformations et fusions si les deux existent. Les catégories vides sont ignorées ; une fusion seule s’ouvre directement. Maintenez la croix ← pour changer de coéquipier. Partenaire, forme, jauges, délais et état du combat restent soumis à BT4. Positions fixes, emplacements vides et barres de vie des réserves sont conservés. En ligne, les panneaux locaux restent à gauche même pour le Joueur 2, sans changer le côté logique des entrées.


## HUD / F6 · F7 · F8

F6: attack panel · F7: outer frame · F8: panel placement. Configure shortcuts and shortcut lock in the launcher. Settings: `%LOCALAPPDATA%\BT4-SparkingControls`.
