# BT4 Sparking Controls 0.6 Test

First public BT4 Windows test release. Includes the earlier BT4 work through 0.6.

- Private in-memory HUD fonts, validated styles and safe fallback for the reported Fira Sans Condensed / Regular error.
- EXE and CMD launch, including nested translation scripts; pre-first-instruction game-process tracking.
- Reviewed compatibility checks tolerate relocated jump tables and direction-name strings while rejecting changed destinations.
- Native Triangle preserved during energy struggles; BT4 boost-glyph alignment corrected.
- BT4 names, portraits and face-centered card crops for transformations, fusion and switching.
- Red BT4 launcher, four-star icon, saved settings, configurable F6/F7/F8 shortcuts, shortcut lock, split-screen and ultrawide placement.

Read the repository README or included English Controls and Setup Guide for installation and commands. Windows x64 only; no BT4 Linux package is provided. This remains a test release; no universal future-build, sustained-FPS or desync-free guarantee.

Special thanks to **Aero** for extensive testing, reproduction details and diagnostic logs.

The ZIP contains the helper EXE, source, documentation, validation reports and AGPL-3.0 license. It does not contain game files, game artwork, texture packs or personal settings.
